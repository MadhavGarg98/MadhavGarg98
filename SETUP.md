# Update steps (5 minutes)

1. Open github.com/MadhavGarg98/MadhavGarg98 > Add file > Upload files.
   Drag in: README.md, assets, data, scripts. Commit changes (this replaces the old files).
2. (Only if you have not done it already) open .github/workflows/scene.yml > pencil icon > Ctrl+A >
   paste the content of copy-paste-workflows/scene.yml > Commit changes.
3. Delete the old snake bot, we draw our own snake now:
   open .github/workflows/snake.yml > three dots (...) > Delete file > Commit.
4. Actions tab > "Update pixel scene" > Run workflow. Wait 1 minute, refresh your profile.
