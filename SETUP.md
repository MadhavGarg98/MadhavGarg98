1. Open github.com/MadhavGarg98/MadhavGarg98 > Add file > Upload files.
   Drag in: README.md, assets, data, scripts. Commit changes (this replaces the old ones).
2. Open .github/workflows/scene.yml > pencil icon (Edit) > Ctrl+A > paste the content of
   copy-paste-workflows/scene.yml > Commit changes.
3. Delete the old bot we no longer use: open .github/workflows/pixel.yml > three dots (...) > Delete file > Commit.
4. Actions tab > "Update pixel scene" > Run workflow. Wait 1 minute, then refresh your profile.
